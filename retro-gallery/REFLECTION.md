1. Explain the difference between flex-direction: row and flex-direction: column.

The difference between flex-direction: row and flex-direction: column is how elements are arranged within a Flexbox container. 
Using flex-direction: row places elements horizontally, from left to right, while flex-direction: column stacks elements vertically, from top to bottom. 
In my website, I used row for the navigation bar on desktop screens and changed it to column for mobile devices.
This allows the navigation links to stack vertically, making them easier to access on smaller screens.

2. Why is it important to use relative units (like %, vh, or rem) instead of fixed pixels (px) for responsive design?
Relative units are important for responsive design because they allow elements to adjust based on the screen size or other factors, such as font size.
Unlike fixed pixels, which maintain the same size regardless of the screen, relative units provide more flexibility when designing for different devices.
For example, percentages allow elements to scale based on their parent container, while vh adjusts based on the height of the browser window.
Using relative units helps prevent layout issues and ensures that a website remains readable and accessible on both desktop and mobile devices.
